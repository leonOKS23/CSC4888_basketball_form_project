# SPL Open Data free-throw dataset — inspection summary
Generated by `scripts/01_inspect_dataset.py`. All facts below were derived
directly from the trial JSON files and the dataset README/notebook, not assumed.

## File layout
- 583 trial files, 5 participants: P0001, P0002, P0003, P0004, P0005
- Path convention: `data/<session_date>/<participant_id>/BB_FT_<participant_id>_<trial_id>.json`
- Session dates found: {'2024-08-28': 125, '2025-12-18': 458}
- IMPORTANT: trial IDs (T0001, T0002, ...) reset at the start of each capture
  session. Participant P0001 has trials from two sessions (2024-08-28 and 2025-12-18); within-participant chronological order is
  therefore sorted by (session_date, trial_number), not trial_number alone.

## Per-trial JSON schema
- Top-level key sets observed (should be exactly 1 unique set): 1
  - 583 files with keys: ['entry_angle', 'landing_x', 'landing_y', 'participant_id', 'result', 'sampling_rate', 'tracking', 'trial_date', 'trial_id']
- `result`: {'missed': 194, 'made': 389}
- `sampling_rate` (fps): {30: 125, 60: 458}
- `landing_x`/`landing_y`/`entry_angle` present (non-null) in all trials: {True: 583} (these describe shot *outcome* — ball position relative to the rim — and are intentionally excluded from model features)

## Keypoints
- Distinct keypoint-name sets across trials: 1
- Keypoint-set size -> number of trials with that many keypoints: {69: 583}
- Example keypoint names (first trial): ['LEFT_ANKLE', 'LEFT_BIG_TOE', 'LEFT_EAR', 'LEFT_ELBOW', 'LEFT_EYE', 'LEFT_FIFTH_FINGER_DIP', 'LEFT_FIFTH_FINGER_DISTAL', 'LEFT_FIFTH_FINGER_MCP', 'LEFT_FIFTH_FINGER_PIP', 'LEFT_FIRST_FINGER_CMC'] ... (69 total)
- Coordinates are in feet, court-centered. `z` is the vertical axis — confirmed empirically: median RIGHT_BIG_TOE z = 0.06 ft, median NOSE z = 5.38 ft (toe near the floor, nose near head height).

## Release event
- The dataset does **not** provide an explicit release frame/event field.
- We estimate it from ball-to-wrist distance (see `spl_ft/release.py` and
  `PROJECT_LOG.md` for the full method and validation). Status counts across
  all trials:
  - ok: 583

## Shooting handedness
- The dataset does **not** provide a handedness field.
- We estimate a per-player shooting side as the majority vote (over trials) of
  which wrist loses contact with the ball last. See `handedness.csv`:
  - P0001: assigned **RIGHT** (213 RIGHT / 0 LEFT votes, 100.0% majority)
  - P0002: assigned **RIGHT** (93 RIGHT / 0 LEFT votes, 100.0% majority)
  - P0003: assigned **RIGHT** (90 RIGHT / 0 LEFT votes, 100.0% majority)
  - P0004: assigned **RIGHT** (89 RIGHT / 0 LEFT votes, 100.0% majority)
  - P0005: assigned **RIGHT** (80 RIGHT / 18 LEFT votes, 81.6% majority)
